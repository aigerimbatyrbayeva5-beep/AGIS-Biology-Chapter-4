# Grade 7 Biology · Chapter 4 · Water and Organic Compounds

The learning website for Chapter 4 at Astana Garden International School (IB MYP Sciences, Year 3): four interactive presentations, student worksheets, lab sheets, English–Russian vocabulary and exit tickets.

- Homepage: `index.html`
- Lessons: `HTML_Presentations/4.1_Water/`, `4.2_Chemical_Elements/`, `4.3_Organic_Compounds/`, `4.4_Macroelements_in_Plants/`
- Publishing and updating: see **README_DEPLOYMENT.md**

Static site with no dependencies or build step at runtime. Rebuild the resource lists after adding files with `python tools/build_site.py`.

Fonts: Plus Jakarta Sans, Cinzel, Nunito and Fredoka (SIL Open Font License, licences in `site/fonts/` and `Assets/fonts/`). AGIS logo © Astana Garden International School. IB MYP logo © International Baccalaureate Organization.
